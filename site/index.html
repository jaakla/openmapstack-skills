ChatGPT desktop · Work with local files

Ask the Skill Installer

  1. Open the ChatGPT desktop app and start a Work conversation with access to your local project.
  2. Paste this request into the conversation:
Use the Skill Installer to install open-map-stack from
https://github.com/jaakla/openmapstack-skills/tree/main/skills/open-map-stack
Include the complete skill folder with its references and templates.

Open Skills in the sidebar to confirm the skill is available, then start a new conversation and try the prompt below.

This path uses standalone skills in the desktop app. For ChatGPT on the web or mobile, reusable skills are distributed through plugins; this repository currently provides direct skill folders and a Claude plugin.

Claude Code · Claude web and desktop

Install the Claude Code plugin

Run these slash commands inside Claude Code to install all four skills:

/plugin marketplace add jaakla/openmapstack-skills
/plugin install open-map-stack@open-map-stack

Start a new session and ask Claude to use open-map-stack.

Using Claude on the web or desktop?
  1. Enable Code execution and file creation in Settings → Capabilities. Managed workspaces may need an administrator to enable skills.
  2. Download open-map-stack.zip.
  3. Open Customize → Skills → + → Create skill → Upload a skill, upload the ZIP, and enable it.

The specialist guidance is already included in open-map-stack.zip. These separate skills offer a narrower scope; upload only the ZIPs you want to use:

  • reproducible-gis-project.zip
  • geospatial-data-discovery.zip
  • spatial-sql.zip

Codex · Local CLI and IDE extension

Install from your terminal

With Git and Node.js (including npx) installed, run this in your project directory:

npx skills add jaakla/openmapstack-skills --skill open-map-stack -a codex -y

Add -g to use the skill across your local projects.

Open Codex in the project and select $open-map-stack. If it does not appear, restart Codex.

Cursor · Local Agent

Install in your Cursor project

Open the project's integrated terminal. With Git and Node.js (including npx) installed, run:

“Use open-map-stack to find authoritative building footprints for Tartu, Estonia. Check coverage and licensing, and propose a reproducible analysis workflow.”

Full workflow or focused task

open-map-stack includes all the guidance. reproducible-gis-project handles manifests and reruns; geospatial-data-discovery finds sources; spatial-sql works with a chosen SQL engine.

The Python CLI is a separate setup for executing and validating projects. See the full installation guide for CLI setup, manual installs, and version pinning.
